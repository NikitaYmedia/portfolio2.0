REAL ESTATE WEBSITE 2026

Luxestate

A multi-page real estate website built from my own mockups with HTML, CSS and vanilla JavaScript. It has a home page, a property catalog with live filters, a property details page and an animated login form. The site works in English and German. What I solved: Built a translation system from scratch that switches all texts and prices and remembers the language. Made filtering work across pages: the home page search passes its filters to the catalog. Drew all icons, the map, the floor plan and the animations in pure CSS.
